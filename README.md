# AI 日报

SmartKey AI 日报的独立前后端项目，保留精选资讯、当前热点与真实热度、日期日历、分类和关键词筛选，以及本站资讯详情和热点事件综述。页面沿用现有样式，侧栏可返回会员中心的 Codex 重置监控。

资讯详情展示导读、推荐理由和事件综述，原作者的完整报道入口保留。精选和热点详情在本站打开，界面不显示聚合来源站的品牌或跳转入口；服务端仍保留来源元数据。

## 本地启动

需要 Node.js 20 或更高版本。生产运行没有第三方依赖，无需安装依赖。

```sh
npm start
```

访问 `http://127.0.0.1:4319/`，会自动进入 `/daily`。普通资讯和热点详情地址为 `/news/{id}`。

可通过环境变量调整监听端口和持久目录：

```sh
PORT=4321 DATA_DIR=./persistent-data npm start
```

默认仅监听 `127.0.0.1`。需要对外访问时使用反向代理；容器内部监听 `0.0.0.0`，Compose 仍仅将端口发布到宿主机 `127.0.0.1:4319`。

## Docker 启动

```sh
docker compose up -d --build
```

服务在 `http://127.0.0.1:4319/`，数据存储在 `daily-data` 持久卷，对应容器 `/app/data`。重建镜像或重启服务会继续使用该卷。备份或迁移时需单独迁移数据卷；删除持久卷会丢失已采集历史。

## 数据与缓存

服务启动后立即采集精选和当前热点，此后每 10 分钟采集一次，不依赖浏览器是否打开。读取来源使用 10 分钟缓存、ETag 和 Retry-After，重启后复用已保存缓存和重试时间。

默认页面展示最近 7 日最新最多 100 条精选。日历列出服务器实际保存的历史日期；选择日期只读取该日历史内容，顶部日期随之切换。点“全部日期”返回最新精选列表。已保存资讯仍可通过本站详情打开。

精选历史按北京时间收录日期归档，合并相同 ID 的最新版本，保存近 180 天。保留期从实际采集的记录开始计算：全新部署没有此前未采集的历史，不会自动补齐过去半年。热点缓存保存当前榜单和已访问的事件详情，事件详情按需更新，不是每日热点快照档案。

默认 `data/` 中包含：

- `daily-feed.json`：最近精选、ETag 与重试状态。
- `daily-archive.json`：近 180 天已采集精选历史。
- `news-feed.json`：热点和事件详情缓存。

数据不会通过静态文件路由公开，也不包含在本源码项目或版本控制中。服务端数据源为固定公开接口，不需要 API 密钥。服务只提供读取页面和资讯的接口，不提供管理账号或写入业务数据的接口。

## 验证

```sh
npm test
```

测试使用临时目录和模拟数据，不请求真实数据源；覆盖缓存、限流、日期验证、北京时间日界、180 天边界、历史详情、失败回退、本站路由和定时采集。页面样式和业务入口与整理前保持一致。
